This Sheets connection is fixed for this app and cannot be changed in Settings.
Apps Script Setup Guide
  1. Open Google Sheets → Extensions → Apps Script
  2. Paste the code from google-apps-script.js (included in this project folder)
  3. Click Deploy → New deployment → Web App
  4. Set "Execute as: Me" and "Who has access: Anyone"
  5. Set the deployed Web App URL in SHEETS_WEB_APP_URL in index.html, then redeploy the app if the URL changes
